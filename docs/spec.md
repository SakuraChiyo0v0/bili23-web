# Bili23-Web 整体规格说明书

> 目标：把桌面版 [Bili23-Downloader](https://github.com/ScottSloan/Bili23-Downloader)（Python + PySide6，v2.15.0）
> **1:1** 迁移为 TypeScript Web 服务，部署于 NAS，通过浏览器完成原版全部下载工作流。
> 行为基准 = 原版桌面程序（本地参照源码 `C:\LocalSpace\Projects\Github-Proj\Bili23-Downloader`）；
> 文档风格与产品结构贴合原版项目，而非本项目作者的其他既有项目。
> 本文件是唯一的产品规格来源；`docs/design.md` 记录实现决策，`docs/superpowers/plans/` 是实施计划。

---

## 0. 术语

- **条目（Item）**：一次解析得到的可下载单元（如一个分P、一集、一首歌），对应原版"解析列表中的一行"。
- **任务（Task）**：用户确认下载选项后创建的下载单元，进入任务队列。
- **附加内容**：弹幕、字幕、封面、章节、NFO 元数据等随视频一起获取/生成的内容。
- **规则引擎**：命名模板与多级目录分类的配置与求值逻辑（对应原版"命名规则/分类规则"）。

## 1. 产品概述

Bili23-Web 是原版 Bili23-Downloader 的 Web 实现，保持同一套产品心智：

- 浏览器粘贴 B 站链接 → 解析出内容树（视频分P/番剧剧集/收藏夹/空间等）→ 勾选条目 →
  设定本次下载的画质/音质/编码/容器与附加内容 → 加入任务队列 → 多线程下载 →
  ffmpeg 合并/转封装 → 按命名与分类规则落盘 → 记录历史、避免重复下载。
- 服务器部署在 NAS，任务在服务端执行，下载产物落在 NAS 磁盘（可 bind mount 到媒体库）。
- 保留原版核心特色：多类型解析、批量、画质音质编码全集、弹幕字幕封面章节 NFO、
  命名与目录规则、重复检测、代理/CDN 选择、剪贴板自动识别（Web 以"粘贴框自动识别"替代）。

### 1.1 与原版的差异原则

1. **行为对齐**：接口参数、画质/音质 id、命名默认值、规则语义、去重逻辑与桌面版一致，桌面版修复时同步。
2. **桌面专有能力裁剪**：系统托盘、窗口记忆、Win7 兼容、模态对话框、剪贴板监听、本机文件选择等不适用，见 §5 对照表。
3. **Web 特有增强**：服务端常驻队列、SSE 实时进度、产物目录在线浏览、浏览器通知，不改变原版下载语义。

## 2. 技术选型

| 层 | 选择 | 说明 |
| --- | --- | --- |
| 运行时 | Node ≥ 22（镜像 node:22-alpine） | 流式/并发下载成熟；内置 `node:sqlite` 免原生编译 |
| 语言 | TypeScript 严格模式 | `strict` + `exactOptionalPropertyTypes` + `noUncheckedIndexedAccess` |
| 引擎 | 纯 Node、零运行时依赖 | 用内置 fetch/undici；框架无关、可单测 |
| 后端 | Hono + @hono/node-server | REST + SSE；TS 类型安全 |
| 前端 | React 19 + Vite；自绘轻量组件（仿 Fluent：左导航+卡片+明暗主题） | 视觉贴近原版；控制体积 |
| 存储 | `config.json` + SQLite（`node:sqlite`） | 数据单文件、备份简单；全部在 bind mount |
| ffmpeg | 镜像 `apk add ffmpeg` | 合并/转封装/MP3/内嵌封面与章节 |
| 测试 | vitest | 引擎 TDD；下载器用本地静态服务器集成测试 |
| 部署 | Docker 多阶段 + ghcr + watchtower | 沿用 NAS 已验证链路；不依赖 PG/配置中心 |

**取舍与理由**
- 不采用旧 TS SDK 与既有 account-panel 技术债（用户指定）。
- 不用 Nest/Fastify：无此复杂度需求；Hono 的 SSE/静态托管已够。
- 不用重 UI 框架（AntD/MUI）：原版是 Fluent 风格，自绘更贴近且镜像更小。
- 存储不用 PG/WebDAV：原版是本地单机配置 + 数据库；NAS 单用户场景 SQLite 足够且更贴合原版。

## 3. 系统架构

```
浏览器 (React SPA)
   │  REST /api/*      SSE /api/tasks/:id/events
   ▼
apps/web  Hono 服务
   ├─ 认证与会话（B站账号登录态管理）
   ├─ 解析/媒体/取流路由（调用 engine）
   ├─ 下载任务管理器（进程内队列，SSE 推送）
   ├─ 产物文件浏览/删除
   └─ 设置读写（config.json）
   ▼
packages/engine（无 UI 依赖）
   ├─ url / parser（按内容类型）
   ├─ media（详情/可选集）
   ├─ stream（画质/音质/编码选择 + DASH/MP4 取流）
   ├─ download（分块并发/断点/重试/限速）
   ├─ ffmpeg（合并/转封装/转换）
   ├─ extras（弹幕/字幕/封面/章节/NFO）
   ├─ naming（命名与目录规则）
   ├─ auth（扫码/短信/Cookie/refresh）
   └─ store（config/任务/历史 SQLite）
   ▼
/data（bind mount）：config.json、db/*.sqlite、logs/、downloads/（可指向媒体库）
```

## 4. 功能规格

> 每条 `R-xx` 为一项需求。验收以"可观察行为"描述，标注是否依赖登录/网络等前置。

### 4.1 内容解析与列表（对齐原版"解析"页）

- R-101 **支持链接类型**：投稿视频、番剧/电影（ep/ss/md）、课程、会员购课程、互动视频、
  B 站音乐（单曲/歌单）、UP 主空间、收藏夹、合集（列表）、每周必看、追番追剧、
  稍后再看、历史记录、活动页（festival）、b23 短链跳转。
- R-102 **批量解析**：一次粘贴多条投稿视频链接批量解析；自动解析分页（原版"自动解析"语义：翻页时延续解析结果并加载后续页）。
- R-103 **条目树与勾选**：解析结果按原版结构组织（多 P/多集/多页分节点），支持单个/整组勾选、全选/反选。
- R-104 **搜索与筛选**：空间/收藏夹/历史/稍后再看支持关键词搜索；支持随链接携带的筛选参数
  （分区/排序/时长等，按桌面版 TODO 同源实现：解析时应用链接参数并展示）。
- R-105 **解析历史与恢复**：记录最近解析的链接，可重新进入；刷新/重进页面不丢已解析内容（服务端会话或本地还原）。
- R-106 **自动勾选**：按预设条件（画质可达/时长范围/是否已下载等）自动勾选条目（对应原版 auto-select）。
- 验收：粘贴 `https://www.bilibili.com/video/BV…` 得到该视频全部分P并可勾选；粘贴 3 条不同视频链接可一次解析出 3 组；空间链接按关键词过滤返回匹配条目。

### 4.2 下载选项（对齐原版"下载选项"对话框）

- R-201 **画质**：自动/8K/杜比视界/HDR/4K SDR 增强/4K/1080P60/1080P+/智能修复/1080P/720P/480P/360P；
  不可用档位置灰并在详情提示原因（需登录/大会员/无该档）。
- R-202 **音质**：自动/Hi-Res/杜比全景声/192K/132K/64K；与画质类似的可达性提示。
- R-203 **编码**：自动/AVC(H.264)/HEVC(H.265)/AV1；按可选列表选择。
- R-204 **输出容器**：mp4 / mkv；弹幕/字幕可嵌入 mkv（ass 嵌入）。
- R-205 **附加内容开关**：弹幕（xml/ass/json + 样式）、字幕（srt/lrc/txt/ass/json + 语言选择 + 样式）、
  封面（jpg/png/avif/webp；可选内嵌后删除原图）、章节、NFO/JSON 元数据（Kodi/Jellyfin/Emby）。
- R-206 **下载范围**：仅音频 / 音视频分离双文件不合并 / 合并成单文件；M4A→MP3 转换开关。
- R-207 **命名与目录**：为本次任务选择命名模板与目录分类规则（默认读全局设置，见 4.5）。
- R-208 **选项固化**：任务创建后，选项固化到该任务；后续改全局设置不影响队列中已有任务（对齐 v2.15 行为）。
- 验收：选择 1080P+HEVC+mkv+ass 弹幕嵌入，产物为单文件 mkv 且内含 ass 弹幕轨（或按原版实现方式呈现）。

### 4.3 下载执行与任务队列（对齐原版"下载"页）

- R-301 **队列与并发**：进程内任务队列；支持"并行任务数"与"单任务线程数"（分块并发）两组配置，
  语义对齐原版 download_parallel / download_thread。
- R-302 **分块下载**：HTTP Range 多段并发写临时文件；断点续传（.part 存在则续传）；网络异常自动重试（次数/退避对齐原版）。
- R-303 **限速**：全局下载限速（KB/s）可配、可即时调整。
- R-304 **进度**：任务级与分片级进度、速度、剩余时间；经 SSE 实时推送；刷新页面状态保留（状态存库）。
- R-305 **控制**：暂停/继续、取消、删除任务；ffmpeg 合并/转换阶段失败可重试且不使队列停滞（对齐 v2.15 修复）。
- R-306 **重复检测**：创建任务时按原版身份哈希规则（bvid/aid/ep/ss 等维度）检查历史，命中则提示并可跳过/覆盖（文件重名策略：自动改名/覆盖）。
- R-307 **产物与日志**：任务完成后在产物目录可见文件；每任务日志可在 Web 查看；全局日志文件轮转（对齐原版 logs/app.log 与历史页）。
- 验收：加入含 10 集的批量任务后，服务重启任务状态可恢复（未完成的续传/标为失败），全部完成后重复加入提示"已下载"。

### 4.4 附加内容生成（对齐原版"附加内容"实现）

- R-401 **弹幕**：拉取 cid 弹幕；输出 xml/ass/json；ass 支持样式配置（字体/字号/颜色/描边/不透明度等，对齐原版弹幕样式）。
- R-402 **字幕**：列出可用字幕语言，选择后输出 srt/lrc/txt/ass/json；字幕样式可配。
- R-403 **封面**：原图保存（jpg/png/avif/webp）；可选把封面嵌入视频文件（mp4 封面原子块/mkv 附件）后删除原图。
- R-404 **章节**：写入 mp4/mkv 章节信息（来源：分P 起止与接口章节）。
- R-405 **NFO/JSON 元数据**：生成符合 Kodi/Jellyfin/Emby 的 nfo 与/或 json（剧集/电影/音乐按原版模板）。
- 验收：下载一个带 2 种语言字幕的视频并选择"简中 srt"，产物目录出现同名 .srt；勾选 NFO 后出现 .nfo 且可被媒体中心识别。

### 4.5 命名与分类规则引擎（对齐原版规则）

- R-501 **命名模板**：每类内容（投稿/番剧/课程/互动/收藏夹/空间/历史/稍后再看/每周必看/音乐）独立模板；
  变量与默认值对齐原版（如标题、分P、集数、UP主、分辨率等占位符）。
- R-502 **多级目录**：分类规则可生成多级目录并按内容类型生效；支持"按解析列表列/标签分目录"等原版维度。
- R-503 **起始编号/补齐**：数字编号起始值、位数补齐规则（对齐原版 Numbering）。
- 验收：配置"番剧：`剧名/Season N/SxxExx - 标题`"后下载番剧落盘路径与该模式一致。

### 4.6 账号与登录

- R-601 **登录方式**：扫码登录（二维码轮询，web 展示二维码）、Cookie 登录；账号状态（头像/昵称/大会员/等级）展示。
- R-602 **会话持久化**：cookie + refresh_token 加密落盘（data/），失效自动续期；多端行为与原版一致（以原版为准：原版单机存 cookie）。
- R-603 **登出与切换**：登出清除会话并可重新登录。
- R-604 **短信登录**：是否纳入见 §10 开放决策（默认不纳入，因风控/成本）。
- 验收：扫码后再次打开页面仍为登录态；下载大会员画质成功；手动登出后高画质提示需登录。

### 4.7 网络、代理与 CDN

- R-701 **代理**：直连/系统代理（跟随环境）/手动代理（HTTP）；与桌面设置一致的三态。
- R-702 **请求定制**：自定义 User-Agent、Host 覆盖（下载域名改写）；WBI 签名内置（img/sub key 自动刷新）。
- R-703 **CDN 节点**：可选 CDN 服务器列表与优先级（对齐原版 cdn 列表配置）；过滤劣质 pcdn/mcdn 链接。
- 验收：手动配置 http 代理后解析与下载均走代理；Host 覆盖后下载 URL 域名被改写。

### 4.8 历史、重复与去重

- R-801 **下载历史**：记录已完成任务（时间/内容/画质/文件路径/大小），支持查看与清除。
- R-802 **重复判定**：按内容身份（分P cid/ep id/音视频 id）判定"同一内容已下载"，与原版哈希口径一致。
- R-803 **解析历史**：最近解析过的链接列表可复点。
- 验收：同一条链接第二次下载时给出"已下载过"提示并允许跳过或强制重下。

### 4.9 设置（对齐原版"设置"页分组）

设置页分组对齐原版：界面、行为、下载、附加内容（弹幕/字幕/封面/章节/元数据）、文件命名、高级、关于/更新。

- R-901 界面：语言（简中/繁中/English/跟随系统）、主题（浅/深/跟随系统）、显示缩放、列表列显隐与宽度。
- R-902 行为：关闭浏览器标签时的行为提示（非桌面语义：下载继续）、剪贴板自动识别开关（Web=粘贴自动识别）、置顶（不适用，裁剪）。
- R-903 下载：下载目录、并行任务数、线程数、限速、文件重名策略、重复下载处理、默认容器。
- R-904 附加内容：各默认格式/语言/样式（弹幕样式、字幕语言与样式）。
- R-905 文件命名：命名规则编辑（模板语法校验、预览）、分类规则、起始编号。
- R-906 高级：画质/音质/编码优先级、CDN 列表、ffmpeg 来源（系统=镜像内置/自定义路径）、代理。
- 验收：修改命名规则后立即对新建任务生效；对已建任务不生效（固化语义）。

### 4.10 Web 界面与交互

- R-1001 页面结构对齐原版主窗：左侧导航【解析 / 下载 / 日志 / 设置】等；解析、下载为核心页。
- R-1002 解析页：URL 输入（支持多条）、解析按钮、关键词（对支持类型）、结果树、勾选、批量选择、下载选项入口。
- R-1003 下载页：任务列表（状态/进度条/速度/剩余/操作），分组（下载中/等待/已完成/失败/历史）。
- R-1004 日志页：实时与历史日志查看（对应原版日志页/日志文件）。
- R-1005 主题与 i18n：明暗主题切换跟随系统；简中/繁中/英文。
- R-1006 实时性：任务进度/日志 SSE；浏览器通知（可选开关）。
- R-1007 会话内解析状态：页面刷新后可恢复当前解析列表与队列视图（服务端保留解析会话 + 任务状态持久化）。
- 验收：在 1920 宽屏与手机宽度均可用；切深色主题与英文后布局与文案正确。

### 4.11 平台与部署特性

- R-1101 **容器化**：多阶段镜像，运行时含 ffmpeg；`NODE_ENV=production`。
- R-1102 **数据**：所有持久数据在 `/data`（config.json、db、logs、downloads、封面缓存）；下载目录可通过设置指向宿主媒体库（compose 增加 bind）。
- R-1103 **健康与日志**：`GET /api/health`；结构化应用日志落盘 `/data/logs/app.log` 并轮转。
- R-1104 **升级**：watchtower label；版本随 `apps/web/package.json`。
- R-1105 **边界**：默认仅内网/网关后使用；如需公网，前置已验证的网关（用户环境现状），Web 本身不实现强鉴权（见 §8/§10）。

## 5. 桌面特性 → Web 适配/裁剪对照

| 桌面特性 | Web 处理 |
| --- | --- |
| 剪贴板监控 | URL 粘贴框自动识别（失焦/回车即解析提示） |
| 系统托盘/最小化 | 裁剪；服务端常驻，与浏览器无关 |
| 窗口位置/大小记忆、高分屏 | 裁剪；响应式布局 |
| 模态对话框（下载选项/重复确认/批量选择等） | 页面内对话框/抽屉 |
| 本机"打开文件位置" | 产物目录在线浏览 + 可下载文件 |
| 多语言/主题 | 保留（跟随系统或手动） |
| 更新检测（桌面内） | 交给 watchtower 镜像升级 |
| 短信登录 | 默认裁剪，见开放决策 |
| 在线播放预览 | 保留"下载前预览"程度；完整播放器二期（非原版核心） |

## 6. 非目标（明确不做）

- 不做点赞/三连/投币等刷量写接口；不做与付费墙绕过相关能力。
- 不做多用户账号体系与细粒度权限（单用户工具；多用户属另一产品）。
- 不做桌面 GUI 保留；不做移动 App。
- 不引入旧 SDK、PG/配置中心等既有项目设施。

## 7. 数据与存储（详见 design.md）

```
/data
├─ config.json       设置（键名语义对齐原版 config.json）
├─ db/
```

## 8. 安全与隐私

- 登录态（cookie/refresh）加密存储；密钥来自环境变量，缺失时仅影响加密（记录告警）。
- 代理出口（解析/取流/下载中转 URL）不暴露给不可信前端；CORS 仅同源。
- 遵循原版使用协议：仅供个人学习研究、非商业；不绕过付费墙；用户自担账号风险。

## 9. 里程碑与验收（实施顺序）

| 期 | 范围 | 出口验收 |
| --- | --- | --- |
| P0 ✅ | 仓库/骨架/CI/部署文件 | `pnpm check` 绿；镜像构建成功 |
| P1 | 投稿视频最小闭环（解析→选项→下载→合并→历史→页面） | Web 完成一部投稿视频下载，产物可播 |
| P2 | 类型铺开（番剧/课程/音乐/空间/收藏夹/每周必看/稍后再看/历史/互动） | 各类型解析+下载冒烟 |
| P3 | 附加内容 + 命名规则 + 批量/筛选 | 产物含附加内容且按规则命名 |
| P4 | 队列 UI/SSE 打磨、设置页全量、限速/恢复、i18n/主题 | 长时间批量稳定 |

每期结束做一次 spec 对齐检查：对照 §4 勾选已满足需求，未满足项进入下期。

## 10. 开放决策清单（实施前确认）

1. 短信登录：默认不纳入（风控/成本），扫码+Cookie 覆盖主要场景。
2. Web 访问保护：默认仅内网/网关；是否要"轻量访问口令"待定。
3. 在线播放器：二期（原版非核心，仅预览需求）。
4. 解析会话保留方式：服务端内存会话（重启丢失，可重解析） vs 落库（重启保留）——P1 定。
5. 产物默认目录是否直接指向现有媒体库 `/volume1/影视/...`（部署时按需加 bind）。

Core capabilities

桌面版能做到的，这里都能做到

不是功能阉割的网页壳，而是把解析、取流、下载、合并、命名整条链路完整移植到 TypeScript。

全类型解析

投稿视频、番剧、课程、音频、收藏夹、合集系列、每周必看、稍后再看、历史、互动视频，共 13 种类型全覆盖。

画质音质自选

4K / 1080P / HDR、HEVC / AV1 编码、Hi-Res / 杜比音质，自动按优先级挑选，也可逐项锁定。

附加内容全家桶

弹幕转 ASS、多语言字幕、封面、章节、NFO 元数据，一键随视频落盘，媒体库直接识别。

灵活命名规则

UP 主、标题、画质、发布时间、分P 序号……任意变量拼装目录与文件名，Emby / Jellyfin 零配置入库。

队列与断点续传

分片并发下载、全局限速、暂停续传、失败重试，重启服务后任务自动恢复，批量下载不丢进度。

NAS 原生部署

Docker 镜像内置 ffmpeg，一条命令拉起；数据持久化到本地目录，watchtower 自动更新。

Workflow

三步，从链接到成品

没有繁琐配置，粘贴即解析，选好即下载。

01

粘贴链接

支持视频、番剧、收藏夹、UP 主空间、合集、活动页，b23 短链自动展开。

02

选择内容

勾选分P、挑选画质音质编码，按需附加弹幕字幕封面章节，命名规则即时预览。

03

落盘 NAS

后台队列下载、ffmpeg 合并，按规则归档到指定目录，手机电脑随时查看进度。

下载中心，一屏掌控

解析结果、画质选择、附加内容、下载队列全部在同一个工作台里完成，不用来回跳转。

## 1. 文档目标、范围与非目标

### 目标
- 让不熟悉原版代码的人能按本文重建出**行为与交互一致**的 Web 前端。
- 明确“哪些必须 1:1 保留，哪些在浏览器里需要替代或裁剪”。

### 范围
- 主窗口结构、三大页面（解析/下载/设置）、登录、收藏夹面板、全部模态弹窗。
- 树勾选、任务状态机、下载选项语义、命名/编号、CDN/代理/优先级等设置字段。

### 非目标（不在本文决策）
- 不决定 Web 技术栈（React/Vue/自绘等）。
- 不规定最终像素级布局（响应式另行设计），但控件构成与交互必须对齐。

## 2. 产品模型（必须先建立的三个心智）

原版由三层心智组成，Web 前端也应沿用：

1. **解析页 = 工作台**：粘贴链接 → 解析出一棵“可下载条目树”→ 勾选 → 下载。
2. **下载页 = 队列**：任务从排队→下载→合并→完成；或失败/暂停/重试。
3. **设置页 = 全局偏好中心**：所有默认值集中在配置里，下载前可被“下载选项弹窗”覆盖并固化到单个任务。

### 2.1 核心主流程（一次典型下载）
```
粘贴链接 → 识别类型 → 解析（可重定向/批量/自动翻页） → 生成解析树
→ 自动/手动勾选 → 媒体信息预览（画质/音质/编码可选集）
→ （可选）下载选项弹窗 → 创建下载任务（选项快照固化）
→ 入队 → 取流解析 → 分片并发下载 → ffmpeg 合并/转封装/转换
→ 附加内容（弹幕/字幕/封面/章节/NFO） → 命名整理落盘 → 标记完成 → 写入历史
```
任何一步失败都有可见反馈（Toast / 任务状态 / 弹窗），并且**失败不污染已完成的其它任务**。

### 2.2 解析类型与 URL 识别（决定前端解析入口）
原版 `util/common/data/url_pattern.py` 按顺序匹配，命中即选定解析类型：

| 类型 | URL 示例 / 匹配 | 说明 |
|---|---|---|
| video | `bilibili.com/video/BVxx`、裸 `BV/av` | 投稿视频；分P、合集、互动视频都从这里进 |
| bangumi | `bilibili.com/bangumi/play/ss\d+`、`ep\d+`、`md\d+` | 番剧/电影/纪录片；类型由接口 `type` 决定 |
| cheese | `bilibili.com/cheese/play/ss|ep` | 课程 |
| lesson | `mall.bilibili.com/lesson/play` | 会员购商城课 |
| space | `space.bilibili.com/{mid}`、`medialist/play` | UP 主页（列表页，可关键词搜索） |
| favlist | `space.bilibili.com/{mid}/favlist`、`list/ml\d+` | 收藏夹 |
| list | `space.bilibili.com/{mid}/lists`、`bilibili.com/list/\d+` | 合集/系列 |
| popular | `bilibili.com/v/popular` | 每周必看 |
| watch_later | `bili23://watch_later` | 稍后再看（需登录，自定义协议） |
| history | `bili23://history` | 历史记录（需登录，自定义协议） |
| audio | `am\d+`、`au\d+` | 音频（单曲/歌单） |
| festival | `bilibili.com/festival` | 活动页（抓页面还原出 bvid） |
| b23 | `b23.tv`、`bili2233.cn` | 短链，先解跳转再按真实链接解析 |

> Web 端没有自定义协议 `bili23://`。历史/稍后再看需用“导航内入口”或“应用内按钮”替代（见 §13）。

### 2.3 条目树（TreeItem）与“叶子/容器”语义
解析结果是一棵树，Web 端同样需要“容器行”与“可下载叶子行”的区分。

- **可下载叶子**：带 `aid/cid/bvid/ep_id/sid` 或商城课定位字段，有真实流。
- **容器/树节点**：只有分组标题（合集、章节、分P、剧集分组），不可直接下载。
- **NEED_PARSE 行**（空间/收藏夹里的视频行）：**不是叶子**，必须“再次解析”才能得到分P；可直接“下载为单个视频”。
- 每种内容的分类通过 `attribute` 位标志表达，Web 端可用枚举/联合类型对应。

### 2.4 三种勾选/自动勾选策略
| 模式 | 行为 |
|---|---|
| 手动 | 解析完不自动勾选，仅记录链接指向项用于预览定位 |
| 全选 | 解析完勾选全部叶子 |
| 条件式 | 按内容类型不同规则：投稿视频可选“仅链接指向的视频/全部分P或合集”；番剧课程可选“仅当前集/全部正片”；其它可选“手动/全选” |

> 自动勾选的判定对象是**链接明确指向的那一项**：单链接指向单个视频则勾那一项；指向整个番剧且配置为全选时勾正片。原版通过解析器返回 `(key, value)` 定位项（video 用 cid、bangumi 用 ep_id），再由 `locate_to_item_by_episode_data()` 找到对应树行。

## 3. 原版源码导览（怎么读）

### 3.1 顶层拆分
| 目录 | 职责 |
|---|---|
| `src/gui/interface/` | 三大主页面：`main_window.py`、`parse.py`、`download.py`、`setting.py` |
| `src/gui/component/` | 可复用 UI 组件（列表/树/卡片/设置卡/基础弹窗/托盘） |
| `src/gui/dialog/` | 全部弹窗（下载选项、登录、设置子弹窗、misc 杂项） |
| `src/gui/component/widget/` | 极小的基础控件（按钮/滚动/分页/搜索/分段/下拉/拖拽列表等） |
| `src/util/` | 业务引擎：parse、download、network、auth、ffmpeg、common（config/enum/data）、thread |
| `src/util/common/signal_bus.py` | **全局信号总线**：UI 与后台线程唯一的通信渠道 |
| `src/util/common/config.py` | 全局配置对象 + 默认值 |
| `src/util/common/enum.py` | 全部分组枚举（状态/类型/模式） |
| `src/main.py` | 启动：日志、崩溃捕获、单实例、翻译、缩放、托盘 |

### 3.3 线程模型（决定前端“异步状态”来源）
- 解析、下载、ffmpeg、封面加载都跑在后台线程；UI 只通过 **signal_bus 信号**收更新。
- 界面上的“正在解析/进度/日志/任务变化”都是事件流，Web 端天然可用 SSE/WebSocket 对应。
- 注意关键点：**解析线程不得直接改 UI 树**，只能发信号；封面是 16 并发下载 + SQLite 缓存。

## 4. 全局外观与行为基准

### 4.1 视觉语言
- 基于 **Fluent Design / Windows 11** 风格组件库 `qfluentwidgets`，不是 B 站官网风格。
- 侧边导航 + 内容区；卡片可“展开/收起”（ExpandGroupSettingCard）。
- 支持浅色/深色主题、主题色；可跟随系统主题。
- 大量“自绘行”：圆角、hover/pressed/selected 背景透明度分层。

### 4.2 通知
- 顶部 Toast（InfoBar）：成功/错误/警告/信息，默认 3 秒，横向；长消息走右下角可关闭 5 秒，内容可滚动。
- 右下系统通知可选（桌面）。Web 用浏览器 Notification 替代。

### 4.3 弹窗通用规则
| 规则 | 说明 |
|---|---|
| 模态 | 应用级模态；部分（如登录）可点遮罩关闭 |
| 置顶 | 打开时随全局“置顶”设置加 WindowStaysOnTopHint |
| Esc | 多数可 Esc 关闭；个别通过 `set_esc_close(False)` 禁止 |
| 大小 | 固定尺寸或相对主窗口百分比（如 60%/65%）；弹窗自动居中于父窗口 |
| 关闭清理 | 对话框关闭即 `deleteLater`（QObject 队列释放） |
| 校验失败 | 在弹窗内顶部 Toast 报错并阻止关闭；输入框标红 |

## 5. 主窗口导航与启动流程

### 5.1 导航项
| 导航 | 对象名/路由 | 位置 | 类型 | 行为 |
|---|---|---|---|---|
| Parser | `ParseInterface` | 顶部 | 页面 | 默认页；其它入口可跳到解析并填入链接 |
| Downloads | `DownloadInterface` | 顶部 | 页面 | 懒加载；导航徽章显示下载中数量（>99 显示 99+） |
| Favorites | `favorite` | 顶部 | Flyout | 弹出收藏夹/追番面板；未登录弹“请先登录” |
| About | `about` | 顶部 | 弹窗 | 关于窗口 |
| Avatar | `avatar` | 底部 | 组件 | 未登录→登录弹窗；已登录→用户卡片 |
| Settings | `SettingInterface` | 底部 | 页面 | 懒加载；首次进入才构造 |

### 5.2 页面懒加载
- `Downloads` 与 `Settings` 都推迟到首次点击才创建（省启动时间）。
- 点击导航按钮时：切换到对应页；设置页首次点击额外手动 `switchTo`。

### 5.3 启动时序（会影响 Web 首屏与引导）
1. 应用级：日志、崩溃钩子、单实例锁。
2. 窗口创建后首屏展示，随后异步：
   - 后台预热网络栈（httpx/SSL）；
   - 创建下载页与托盘（`init_deferred_ui`）；
   - 探测 ffmpeg；
   - 启动系统主题监听、检查更新。
3. **必须接受使用协议**（首启）：不接受 → 直接退出。
4. 首启引导：新手引导弹窗（引导看文档）；地区选择弹窗。
5. 未登录：头像旁显示 TeachingTip“点击头像登录”。
6. 启动后检查：下载目录不可写 → 长错误提示；无 ffmpeg → 错误提示。

### 5.4 关闭行为（对应 Web 的“退出/离开页面”）
`when_close_window` 三选一（设置 Behavior → Window Behavior）：
| 选项 | 行为 |
|---|---|
| Exit the program | 直接退出 |
| Minimize to system tray | 隐藏窗口，进程常驻，任务继续 |
| Always ask | 弹 ExitDialog：选退出或最小化；“不再询问”会把选择写回设置 |

> Web 中“最小化到托盘继续下载”可由“后台任务不随页面关闭而终止”对应——服务端队列常驻天然满足，但需明确告知用户“关掉页面≠取消下载”。

### 5.5 窗口状态
- 记忆窗口位置/大小（可选）；静默启动（隐藏窗口直接常驻）；窗口置顶。
- Web 对应物有限：浏览器不能记住窗口几何、不能置顶；这些设置要么裁剪要么用“打开独立窗口”近似。

## 6. 解析页（ParseInterface）

> 对应原版 `gui/interface/parse.py`。这是整个应用的**核心工作台**，Web 端 1:1 优先级最高。

### 6.1 页面布局（自上而下）
```
[ 链接输入框...................................] [ Parse ▾ ]     ← 顶栏
[ 类别与数量标签        (右) 🔍 历史 🗂 批量选 ⚙选项 ]     ← 工具条
[ 解析结果树（表头：序号☑ | 标题 | 备注 | 时长 | 时间） ]     ← 主体
[ 分页器/搜索结果条/季选择 ] [ 下载进度提示 ] [ 下载选中项 ]   ← 底栏
```

### 6.2 顶栏输入与解析按钮
- 输入框占位文案：“Link / av / BV / ep / ss / md / Favorites / Profile”。
- 输入框右侧动作：粘贴并解析（取剪贴板内容直接解析）、清空按钮；回车触发解析。
- Parse 按钮为“带不确定进度态的拆分按钮”：解析过程中进入 Indeterminate 状态（不可重复点）。
- Parse 下拉菜单（RoundMenu）只有一项：**Batch Parse（批量解析）**。

### 6.3 工具条按钮与对应弹窗
| 按钮 | 行为 |
|---|---|
| 搜索 🔍 | 打开 SearchDialog（见 §6.9） |
| 解析历史 🕘 | 打开 ParseHistoryDialog（见 §8.6） |
| 批量选择 🗂 | 打开 BatchSelectDialog（行号选择，支持 `1,3,5-10`）并高亮勾选 |
| 下载选项 ⚙ | 打开 DownloadOptionsDialog（预览信息有效时才可打开，见 §7） |

### 6.4 解析结果树的列与内容
| 列 | 内容 | 说明 |
|---|---|---|
| 序号 ☑ | 勾选框 + 行号/分组标签 | 勾选状态只在序号列 |
| 标题 | 叶子标题 | 高亮搜索命中 |
| 备注 | badge（如“充电专属”“预告”） | |
| 时长 | 已格式化（秒→可读） | |
| 时间 | 按类别取发布/收藏/观看时间 | FAVORITES/WATCH_LATER→收藏时间，HISTORY→观看时间，其余发布 |

- 列可在设置里增删/重排/调宽；序号列固定最前且不可隐藏、不可拖动。
- 隔行变色、悬浮命令条可在设置开关。

### 6.5 行结构与层级展示
- 每行数据 = `TreeItem`（`attribute` 位标志 + 展示字段 + `related_titles` 命名上下文）。
- 常见层级（树节点不计入可勾选叶子）：
  - 单视频：根（投稿视频）→ 1 个叶子（视频）。
  - 分P：根（分P，父标题）→ N 个叶子（P1..Pn，带 part_number）。
  - 合集：根（合集）→ 章节（可选，仅多章节时）→ 视频（若多P再包一层）→ 叶子。
  - 番剧：根（剧名）→ 章节（正片/其它）→ 叶子。
  - 空间/收藏夹：根（UP名/收藏夹名）→ 视频行（NEED_PARSE，可再解析）。
- 分类通过 `attribute` 决定列“时间”语义、命名规则类型、自动勾选策略等。

### 6.6 勾选系统（Web 必须精确复刻）
- 三态：Checked / Unchecked / PartiallyChecked。
- **父节点勾选/取消** → 递归下传到全部叶子；**叶子变化** → 向上重算父状态（全选→Checked、全不选→Unchecked、否则半选）。
- 半选节点点击 → 视作“向全选”切换（见批量逻辑注释）。
- Shift + 单击行任意处 = 从“上一次手动点击的锚点”到目标行的**范围勾选**（跨展开项、折叠节点按整组处理；回拖可还原会话内被移出范围项的原始状态）。
- 快捷键：Ctrl+A 全选、Ctrl+D 全不选、Ctrl+F 搜索。

### 6.7 悬浮命令条与右键菜单（叶子行）
悬浮（hover）在行末显示三个图标动作：
1. **Parse this item**：以该行 URL 重新解析（跳回解析页）。
2. **View Multi-part Video List**：仅当该行是收藏夹中的分P视频时可用 → 弹出分P列表对话框。
3. **Download as Single Video**：将该行直接作为一个下载任务（特殊命名规则）。

右键菜单：
```
[全选/全不选]  [反选]
----------------------
[勾选/取消该项]
----------------------
解析该项 | 浏览器打开 | 下载为单个视频 | 更新媒体信息
----------------------
查看元数据 | 查看封面        (叶子行才有封面)
```

### 6.8 媒体信息预览（下载前能力探测）
- 解析成功且存在叶子后，自动对“链接指向的视频”发起媒体预览；链接未指向具体视频时取第一个叶子。
- 解析出的叶子作为候选：首选无权限（充电专属/付费等）时自动换用后备叶子，最多 3 个；全部失败才报错。
- 预览信息全局缓存（含画质/音质/编码候选与已查真实大小）；“更新媒体信息”可强制重查。
- Web 端等价物：选中集合的“媒体信息/可选流”预取。这是下载选项弹窗数据来源。

### 6.9 搜索
搜索分两类（SearchDialog）：
- **本地筛选当前页**：对当前树标题做大小写不敏感子串匹配；结果条显示 `x of n`，可上一项/下一项，可“全选匹配/清除匹配”，命中行高亮并滚动。
- **服务端搜索全部**：仅空间/收藏夹/历史/稍后再看支持（接口带 keyword/key）。做法 = 把关键词写回当前链接的参数后重新解析整页（关键词随链接保留，翻页/自动分页都沿用）。合集/每周必看等分页接口无服务端搜索，提示“只能筛当前页，如需全量请先解析全部分页”。

### 6.10 分页 / 季切换 / 自动解析分页
- 支持分页的解析结果在底部显示 **Pager**：上一页/页码按钮（带首尾省略 `...` 的连续窗）/下一页/跳页按钮/自动解析分页按钮。
- 切换页 → 以当前链接+页码重新解析。
- 番剧解析结果带季选择：同一剧集系列多个 season 时，底部下拉“第X季”，切换即用 `ss{id}` 重解析（同一系列切换不重置数据）。
- 当解析结果分页且总页数>1 时：首次显示教学气泡；若设置开启则自动弹 **AutoParseDialog**（自动解析分页），见 §8.4。

### 6.11 解析成功/失败处理
| 事件 | 行为 |
|---|---|
| 成功 | 更新类别标签；重建/追加树；恢复按钮；若开启“保存解析历史”则异步写入历史 |
| 失败 | 按钮复位；隐藏进度提示；**清空当前解析树**与搜索态；顶部 Toast 报错 |

### 6.12 剪贴板监控（桌面能力）
- 开启后监听系统剪贴板：内容为文本且命中 URL 模式 → 自动填入输入框并解析（带 `_triggered_by_clipboard` 标志）。
- 若开启“下载确认对话框”，且由剪贴板触发的解析完成后存在勾选项 → 自动弹下载选项/确认。
- Web：浏览器剪贴板权限替代；交互上建议改为“粘贴框自动识别+确认”，不强制自动解析。

### 6.13 自动解析分页/批量解析（进度型任务）
- 自动解析分页：范围“全部页”或“第X到Y页”；解析间隔（0.1–15 秒，默认 2）；可选“每页解析后自动加入下载列表”；警告反爬风险。
- 批量解析：多行 av/BV（仅 av/BV），去空行后逐条解析，进度提示条“正在解析 x/N”。
- 互动视频：解析到互动视频时弹窗询问“是否自动解析全部节点”，支持停止；后台 BFS 遍历全部选项分支生成叶子，逐节点上报进度。

5. **Metadata**：下载开关；格式 nfo/json（媒体中心刮削）。

### 7.4 页签 3：Download Settings
- 下载目录（此弹窗修改即改全局默认）。

### 7.5 保存语义（Web 必须保留）
- 点击 OK 后把页面选择写入**全局配置**（media：画质/音质/编码/下载视频/下载音频/合并/保留原文件/保留类型；download：目录/容器/命名规则/编号等）。

### 7.6 底部“Will download”实时预览条
- 彩色标签，一项对应一种可下载内容：Video / Audio / Danmaku / Subtitles / Cover / Chapters / Metadata。

## 9. 任务状态机（下载生命周期）

### 9.1 状态全集（原版枚举值）
| 状态 | 原值 | 含义 |
|---|---|---|
| QUEUED | 0 | 排队中（等待调度） |
| PARSING | 1 | 正在取流（解析下载链接） |
| DOWNLOADING | 2 | 下载中（分片并发） |
| PAUSED | 3 | 已暂停（断点保留） |
| COMPLETED | 4 | 已完成 |
| FFMPEG_QUEUED | 5 | 等待 ffmpeg（最多同时 1 个） |
| MERGING | 6 | 正在合并 |
| CONVERTING | 7 | 正在转换（如 mp4/mkv、m4a→mp3） |
| ADDITIONAL_PROCESSING | 8 | 附加内容处理（字幕/封面等） |
| FAILED | 100 | 下载失败 |
| FFMPEG_FAILED | 101 | ffmpeg 失败 |
| INVALID | 1000 | 无效（移动/删除临时文件导致无法继续） |

### 9.2 状态流转
```
创建(入 downloading 表) → QUEUED
QUEUED → PARSING → DOWNLOADING
DOWNLOADING ⇄ PAUSED（断点）
DOWNLOADING → FFMPEG_QUEUED → MERGING / CONVERTING → ADDITIONAL_PROCESSING → COMPLETED
DOWNLOADING → FAILED；MERGING/CONVERTING → FFMPEG_FAILED
COMPLETED →（重新下载）→ 重置后回到 downloading 表并重下
任何状态（除合并/转换中）→ DELETE（删除任务+临时文件）
```
- 取流（PARSING）失败会自动重试一次；仅对可重试接口错误（-352/-412/-500/-504/-509 等）重试，其余直接失败。
- 任务完成后自动从 downloading 表移到 completed 表并刷新两个列表；若全部下载任务结束且开启通知 → 发“下载完成”通知。

### 9.3 卡片文案映射（影响 UI 展示）
| 状态 | 副标题/状态文字 |
|---|---|
| QUEUED | “排队中” |
| PARSING | “解析中” |
| DOWNLOADING | 实时速度（如 5.2 MB/s） |
| PAUSED | “已暂停” |
| FFMPEG_QUEUED | “等待 FFmpeg 处理” |
| MERGING/CONVERTING | “合并中 xx%”/“转换中 xx%” |
| ADDITIONAL_PROCESSING | 自定义附加处理文案 |
| COMPLETED | “已完成” |
| FAILED | “下载失败” |
| FFMPEG_FAILED | “FFmpeg 处理失败” |
- 大小列：未完成显示 `已下 / 总量`；完成/等待ffmpeg/合并/转换后只显示总量。

| 封面 | jpg / png / avif / webp | 非 avif → 嵌入视频 |
| 章节 | — | MKV ffmetadata |
| 元数据 | nfo / json | 不嵌入，落盘媒体库 |

样式相关子弹窗：
- 弹幕样式：字体（族/字号/粗斜下划/删除线）、描边+阴影 px、高级（显示区域 %、不透明度、滚动时长、停留时长、最小间距）、分辨率（宽/高）。
- 字幕样式：同上字体/描边 + 颜色组（主色/次色/描边/阴影，ASS 色值 &HAABBGGRR）+ 边距（左/右/垂直）+ 对齐 + 分辨率。
- 字幕语言：单选“下载全部字幕/仅指定”，指定用可勾选列表展示语言列表（语言文档名 + lan code）。

## 12. 登录与用户入口

### 12.1 登录弹窗（LoginDialog）
- 左侧：**扫码登录**区（二维码图 160×160 + 状态文字 + 提示“用 B 站 App 扫码”）。

### 12.3 登录态边界
- 历史记录 / 稍后再看 / 收藏夹与追番面板需登录。

## 13. 命名/编号/CDN/选流等横切规则

### 13.1 命名规则类型（ConventionType）
`NORMAL(11) / PART(12) / COLLECTION(13) / INTERACTIVE_VIDEO(14) / BANGUMI(20) / CHEESE(30) / LESSON(31) / FAVORITE(40) / SPACE(50) / HISTORY(60) / WATCH_LATER(70) / WEEKLY(80) / AUDIO(90)`
- 每种类型有默认规则模板（如 PART=`{parent_title}/P{p}-{leaf_title}`，BANGUMI=`{season_title}/{episode_title}`，FAVORITE=`{favorites_owner_id}_{favorites_owner}/{favorites_name}/{leaf_title}` 等）。
- 规则按类型“一对一默认”，同一类型有且仅有一个 `default`。
- 特殊规则：**下载为单个视频**时强制 `{leaf_title}`（无视所选类型模板）。

### 13.2 模板变量（编辑器的变量表 = 实际支持的字段）
| 变量 | 说明 |
|---|---|
| `{number}` | 序号（编号模式决定来源） |
| `{pub_time}` `{pub_ts}` `{create_time}` `{create_ts}` `{fav_time}` `{fav_ts}` `{last_watched_time}` `{last_watched_ts}` | 时间变量（支持 `:%Y-%m-%d_%H-%M-%S` 等格式） |
| `{uploader}` `{uploader_uid}` | UP 主/UID |
| `{video_quality}` `{audio_quality}` `{video_codec}` | 实际选择的画质/音质/编码文本 |
| `{leaf_title}` `{parent_title}` `{section_title}` `{collection_title}` | 各级标题（“叶子/父/章节/合集”） |
| `{series_title}` `{season_title}` `{episode_title}` | 剧集标题层级 |
| `{p}` `{season_number}` `{episode_number}` | 分P/季/集序号 |
| `{aid}` `{bvid}` `{cid}` `{ep_id}` `{season_id}` | id 类 |
| `{course_id}` `{lesson_id}` `{item_id}` `{section_id}` | 商城课定位 |
| `{favorites_name}` `{favorites_id}` `{favorites_owner}` `{favorites_owner_id}` | 收藏夹上下文 |
| `{space_owner}` `{space_owner_id}` | 个人空间上下文 |

- 校验规则：模板不得以 `/`、`.`、`..` 开头或结尾；路径分段中不允许 `<>:"/\|?*` 与控制字符；预览对非法字符自动替换为 `_`；路径组件剥离首尾点/空格。

### 13.3 画质/音质/编码 id 与优先级
- **视频画质** 特值 `200 = 自动（按优先级）`；具体 id 127/126/125/122/120/116/112/100/80/64/32/16（8K→流畅）。
- **音频音质** 特值 `30300 = 自动`；30251(Hi-Res)/30250(杜比全景声)/30280(192K)/30232(132K)/30216(64K)。杜比 30255 归一到 30250。
- **编码** 特值 `20 = 自动`；7(AVC)/12(HEVC)/13(AV1)。
- 当“自动”或指定 id 不存在时：按配置的优先级列表取第一个可用；仍无则失败/裁剪该项下载类型。
- UI 上“Auto”显示为可选项，具体候选项只列接口真实返回的。

### 13.4 媒体类型判定（影响下载与扩展名）
- `DASH`：video+audio 分片（.m4s），走合并。
- `MP4`/`FLV`：单文件或多 durl 分段（分段需要下载后按列表合并）。
- `M4A`：音频直链（.m4a），可 m4a→mp3。
- `audio/lesson` 等直链即成品，不走 ffmpeg（除非转换）。

### 13.5 下载 URL 选路（CDN 探测）
- 候选 = 原站 URL + 可选替换为服务商节点 URL，分“首选层”与“兜底层”。
- 过滤 pcdn/mcdn/已知劣质域名；同一节点失败 2 次进入 180s 冷却并排到末尾。
- 探测用 HEAD 优先、Range GET 兜底，取 >1024B 的首个成功项；单批并发 4、总预算 30s（首选层只占 60%）。
- 商城课直链（含 `mallxcodeboss`）不替换节点。

### 13.6 任务编号（NumberingType）
| 模式 | 说明 |
|---|---|
| FROM_SPECIFIED | 每批从 1 开始（批量解析/自动解析触发时重置） |
| USE_PARSE_LIST | 使用解析列表显示的行号 |
| CONTINUOUS | 全局递增（`global_starting_number`，可在设置修改） |

## 14. 桌面能力 → Web 映射/裁剪表

| 桌面能力 | Web 处理建议 | 可裁剪? |
|---|---|---|
| 系统托盘、最小化到托盘、静默启动 | 后台任务由服务端常驻；页面关闭不等于取消任务 | 可裁剪入口，语义保留 |

| 剪贴板全局监听 | 粘贴事件/权限请求替代 | 替代 |
| 系统原生通知 | Notification API | 替代 |
| 文件对话框（ffmpeg 路径/导入导出配置/打开下载目录） | Web 侧改为输入路径 / 上传下载 / 打开新页 | 替代 |

| Mica/亚克力/高DPI 缩放 | CSS 近似 + 浏览器缩放 | 替代 |

| 自定义协议 `bili23://history` 等 | 应用内按钮/URL 路由 | 替代 |

## 15. 产品决策（已确认）

> 以下为 2026-09-04 与产品方确认的决策，作为实现约束。

1. **整体结构/信息架构 1:1 对齐原版；视觉可 Web 化增强。**
   - 允许：更多动效、改变配色、加入响应式。
   - 不允许：删改页面/弹窗结构、改变核心交互语义（树勾选、下载选项、任务状态等）。
2. **登录方式只做扫码 + Cookie，不做短信登录。**
3. **分页/自动解析分页等交互需要保留**（会显著增加前端复杂度，但按 1:1 要求保留）。
4. **桌面专属能力按 §14 映射/裁剪表执行。**
5. **“使用协议”保留在 Web 端**：首次使用需接受后才能继续使用（在 Web 中以弹窗/欢迎页呈现，接受状态写入配置）。

### 仍需在产品/设计阶段细化（不影响本文档基线）
- 配色主题（默认浅/深/跟随系统；具体色板与强调色待定）。
- 动效强度与“减少动态效果”可访问性选项。
- Web 端“扫码登录二维码”的数据来源与刷新机制（由后端接口提供）。

## 17. 移动端与响应式适配（2026-09-04 新增要求）

> 需求：Web 端同时适配**手机端**，采用响应式方式。本节给出页面级的移动端策略，作为前端实现约束，
> 不规定具体 CSS 断点数值（由实现时视觉稿确定），但**信息架构与核心交互语义不可因移动端降级而缺失**。

### 17.1 原则
1. **同一套代码/路由，响应式布局**：桌面（宽屏）与手机（窄屏）共享组件与状态。
2. **内容不减，入口重组**：不在移动端删除功能；通过抽屉/底部导航/折叠面板承载。
3. **桌面 1:1 结构 = 移动端的“信息层级”基准**：先桌面完整结构，再移动端把并列区收进抽屉/Tab。
4. **动效增强以不阻塞为准**：移动端注意减少非必要入场动画；提供“减少动态效果”偏好（§15.3）。
5. **触控目标 ≥ 44×44px**、文本不小于浏览器默认；避免纯 hover 依赖（解析树悬浮条等必须有替代入口）。

### 17.2 断点建议（实现时可调）
| 档位 | 典型宽度 | 布局策略 |
|---|---|---|
| 桌面 | ≥ 1024px | 左侧导航常驻；解析树多列表；下载列表卡片横排 |
| 平板 | 768–1023px | 导航可折叠为图标栏或抽屉；树列适当缩减 |
| 手机 | < 768px | 抽屉导航 / 底部导航；解析树简化为“标题+状态”两列+展开查看；下载卡片纵向化 |

### 17.3 主窗口 → 移动端
- 原左侧导航（Parser/Downloads/Favorites/About/头像/Settings）：
  - 建议**底部 TabBar**（解析 / 下载 / 设置）+ 收藏夹、头像、关于放入顶栏或“更多”。
  - 头像与登录入口放在顶栏右侧或“我的”页。
- 使用协议、地区引导等弹窗在手机上改为全屏底部 Sheet，保持“接受后才能继续”。

### 17.4 解析页 → 移动端
- 输入框 + 解析按钮占满首屏；批量解析等次级动作放入输入框“更多”菜单。
- 工具条按钮（搜索/历史/批量选择/下载选项）横向滚动或收进溢出菜单，不能用 hover。
- 解析树：
  - 桌面为多列表格；手机上**降为“两列（勾选+标题）列表”**，备注/时长/时间作为次要信息折叠或仅展示于行详情。
  - 排序/列显隐设置仍保留（可在设置中按列开关），但移动端默认展示标题列即可。
  - 悬浮命令条（解析/查看多P/下载单视频）在移动端改为**行内更多按钮**或长按菜单。
  - Shift 范围勾选在触屏无意义 → 保留“全选/反选/批量选择行号”入口即可（原版设置页/右键仍可到达）。
- 底部分页器：页码过多时使用“上一页/下一页 + 跳页”，页码省略策略沿用。
- 季选择 / 搜索结果条保持在工具条/底部区域。

### 17.5 下载选项弹窗 → 移动端
- 桌面 750×500 三页签弹窗 → 手机上改为**全屏页面（步骤式）或底部可滚动 Sheet**。
- 页签切换保持“媒体设置 / 附加文件 / 下载设置”三区不变。
- 底部“Will download”预览条始终可见（可吸底），保证用户确认前看得到将要下载内容。
- 确认类强提示（无声、不合并等）沿用弹窗，但移动端用居中对话框或底部 Sheet。

### 17.6 下载页 → 移动端
- Downloading/Completed 双 Tab 保留（顶部或 Segmented）。
- 批量按钮（Start All/Pause All/Delete All/Clear All/排序/打开目录）收进右上“更多”菜单；核心操作仍可直接触达。
- 任务卡片：封面 + 标题 + 副信息 + 进度/状态；桌面主按钮（暂停/继续/打开目录/重试）+ 删除两个按钮，手机上可合并为一个主按钮 + 更多菜单。

### 17.7 设置页 → 移动端
- 滚动分组布局本身天然响应式；仅需让卡片单列撑满、组间距适当。
- 含滑块的并发/线程设置，触屏滑块需保证可操作区域足够。

### 17.8 登录 → 移动端
- 手机端扫码登录不便 → **扫码 + Cookie 都要保留**；在手机上可强调“Cookie 登录”，并提供“桌面端扫码”引导。
- 二维码区域（若后端提供）在手机上仍可显示；扫描建议用另一台设备。

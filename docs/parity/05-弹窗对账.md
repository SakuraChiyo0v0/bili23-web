## §7 收藏夹浮层（原版 §4）

> **2026-09-13 变更（用户要求）**：收藏夹**不再是浮层/弹窗，改成内容区页面 `#/favorites`**。
> 原版是 `FavoriteFlyoutWidget`（`SLIDE_RIGHT` 非模态侧滑），我们第一版做成了模态弹窗、
> 后来按原版改成浮层 —— 现在按用户要求做成页面：功能与信息层级完全不变
> （5 个分类、刷新 / 在浏览器中打开、追番两个下拉 + 分页器、右键菜单、未登录拦截都还在），
> 只是承载形态从"侧滑浮层"变成"页面"。这属于第 ③ 条允许的 **UI 形态差异**（页面可直达、可分享、
> 前进后退可用，也不必自己写遮罩与点外关闭、移动端不必做 sheet）。

**2026-09-13（续九）· `A2` 媒体信息卡的逐行明细（账上最后一条「有但简化」）**

原版每张下拉下面都有一行**副标题**，我们以前只在选项文本里带个带宽、底下加一句"时长/约合"。
现在按 `MediaInfoCard`（`card.py:104-190`）补齐：

| 原版 | 现在 |
|---|---|
| 「媒体信息来源」行 `#{number} - {content}` | 补上（用本次条目的分P 序号 + 标题拼；批量下载时媒体信息只探测首个条目，这行是必要的） |
| 画质行副标题：画质 / 帧率 / 码率 / 大小（MP4 再补一个 MP4） | `480P，25.0 fps，412.3 Kbps，23.82 MB` |
| 音质行副标题：音质 / 编码 / 码率 / 大小 | `192K，AAC LC，319.1 Kbps，18.44 MB` |
| 编码行副标题：编码 / 说明（体积与兼容性） | `AVC/H.264，文件体积大，兼容性强` |
| 无音轨时给**原因**（DASH / MP4 / UNKNOWN 三种） | 无音频流时显示「无声视频流，不包含音轨」/「视频流中已包含音轨」/「将按优先级自动选择音质」 |
| `Fetching...`=正在获取... | 加载时显示「正在获取...」 |

**为此改的数据链路**（原来缺字段，前端做不出来）：
- 引擎 `StreamRef` 加 `frameRate`（playurl 的 `dash.video[].frameRate` 是字符串，如 `"60"`）并透传；
- `/api/media/:itemId` 的画质项补 `frameRate`/`width`/`height`（DASH）与 `size`（MP4/durl 的**真实**字节数）；
- 音质项补 `audioCodecId` 与 `audioCodecs`（原版用 `reversed_audio_codec_map` 把 `mp4a.40.2`→`AAC LC`、`fLaC`→`FLAC`，认不出就原样显示）。

**单位格式化**照原版 `util/format/units.py` 另起一套（**不要**和任务卡的 `fmtBytes` 混用）：
文件大小 1024 进制**两位小数**、码率 1000 进制、帧率 `{:.1f} fps`；
另外 DASH 没有真实 size，按"码率 × 时长 ÷ 8"估算并标成「约合」，MP4 用接口给的真实值。
落点 `lib/mediaText.ts`（纯函数 + **6 条单测**）。

en: ["480P, 25.0 fps, 412.3 Kbps, 23.82 MB",

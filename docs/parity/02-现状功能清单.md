## 附：两个具体问题的直答

**问题 1：`apps/web/src/client/` 里哪些页面真能用，哪些是空壳？**

- 真能用（3 个页面，全部有真实 API 往返）：`ParsePage`（解析/勾选/批量/搜索/右键/下载选项）、`TasksPage`（任务列表/暂停继续重试删除/SSE/日志/通知）、`SettingsPage`（6 组设置，其中绝大多数项有服务端读取点）。
- **没有任何"占位页"在跑**：唯一的 `PlaceholderPage` 实际不可达（路由回落到解析页），所以"空壳页"问题不存在，真正的问题是**页面数量少**——原版的日志页、下载历史页、产物浏览页根本没有，而不是"摆了个空页面"。
- 半空壳的是页面内的**局部区域**：设置页的"优先级"行、界面组的"Mica/缩放"行、行为组的"剪贴板/窗口行为"行、高级组的"MCP/日志查看器/检查更新"行——它们只是带"—"的说明行，不是可交互控件。
